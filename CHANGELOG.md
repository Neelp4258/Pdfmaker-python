# Changelog

All notable changes to HTML2PDF service will be documented in this file.

## [1.1.0] - 2024-01-09

### Added
- 🎨 Modern web UI with CodeMirror HTML/CSS editor
- 📝 Built-in templates (Invoice, Report, Resume, Presentation)
- 🌙 Dark mode support
- 📊 Real-time job queue visualization and status tracking
- 📱 Fully responsive design for mobile/tablet/desktop
- 📄 Interactive API documentation page
- 💾 Job history with local storage
- 🎯 Visual configuration panel for all PDF options
- 📤 File upload support for HTML files
- 🔔 Toast notifications for user feedback

### Improved
- Enhanced user experience with visual controls
- Better error messages and user guidance
- Streamlined workflow for PDF generation

## [1.0.0] - 2024-01-08

### Added
- 🚀 Initial release
- Flask API with async/sync endpoints
- Playwright + Chromium for PDF rendering
- Celery + Redis job queue
- API key authentication
- Rate limiting
- SSRF protection
- HTML sanitization
- Multi-format support (A4, Letter, Legal, etc.)
- Custom dimensions and aspect ratios
- Docker and Kubernetes deployment
- Comprehensive tests
- Python, Node.js, and cURL examples
