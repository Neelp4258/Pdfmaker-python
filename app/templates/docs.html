API Documentation

Complete reference for the HTML2PDF API

Back to App

Authentication

All API requests require an API key. Include it in your requests:

Header: X-API-Key: your-api-key
Query: ?api_key=your-api-key

Endpoints

POST /render-sync

Generate PDF synchronously (immediate response)

Request Body:

{
  "html": "<html>...</html>",  // OR "url": "https://..."
  "format": "A4",                    // A4, Letter, Legal, etc.
  "width": "210mm",                  // Custom width (optional)
  "height": "297mm",                 // Custom height (optional)
  "aspect": "16:9",                  // Aspect ratio (optional)
  "landscape": false,                // Orientation
  "margin": "10mm",                  // Margins
  "scale": 1.0,                      // Scale factor (0.1-2.0)
  "page_ranges": "1-5, 8",           // Specific pages
  "css": "body { color: red; }",     // Custom CSS
  "wait_for": "#content"             // Wait selector or timeout
}

Response:

PDF file (application/pdf)

POST /render

Queue PDF generation job (asynchronous)

Request Body:

Same as /render-sync

Response:

{
  "job_id": "uuid",
  "status": "queued",
  "status_url": "/status/uuid"
}

GET /status/<job_id>

Get job status

Response:

{
  "job_id": "uuid",
  "status": "completed",  // queued, running, completed, failed
  "download_url": "/download/uuid",
  "size_bytes": 12345
}

GET /download/<job_id>

Download generated PDF

Response:

PDF file (application/pdf)

POST /batch

Queue multiple PDF generation jobs

Request Body:

{
  "jobs": [
    {"html": "...", "format": "A4"},
    {"url": "...", "format": "Letter"}
  ]
}

Response:

{
  "jobs": [
    {"job_id": "uuid1", "status": "queued"},
    {"job_id": "uuid2", "status": "queued"}
  ]
}

Page Formats

  • A4: 210 × 297 mm
  • A3: 297 × 420 mm
  • A5: 148 × 210 mm
  • Letter: 8.5 × 11 in
  • Legal: 8.5 × 14 in
  • Tabloid: 11 × 17 in
  • Receipt: 80mm wide
  • Custom: Specify width and height

Aspect Ratios

  • 16:9 - Widescreen
  • 16:10 - Widescreen alternative
  • 4:3 - Standard
  • 3:2 - Photo
  • 1:1 - Square

Dimension Units

  • mm - Millimeters (e.g., "210mm")
  • cm - Centimeters (e.g., "21cm")
  • in - Inches (e.g., "8.5in")
  • px - Pixels at 96 DPI (e.g., "800px")
  • pt - Points (e.g., "72pt")

Examples

cURL

curl -X POST http://localhost:5000/render-sync \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"html": "<h1>Hello</h1>", "format": "A4"}' \
  --output document.pdf

Python

import requests

response = requests.post(
    'http://localhost:5000/render-sync',
    headers={'X-API-Key': 'your-key'},
    json={'html': '<h1>Hello</h1>', 'format': 'A4'}
)

with open('document.pdf', 'wb') as f:
    f.write(response.content)

JavaScript

const response = await fetch('http://localhost:5000/render-sync', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your-key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    html: '<h1>Hello</h1>',
    format: 'A4'
  })
});

const blob = await response.blob();
// Download or use the PDF blob

Rate Limits

Default rate limits:

  • 60 requests per minute
  • 1000 requests per hour

Rate limit headers are included in responses:

X-RateLimit-Minute-Limit: 60
X-RateLimit-Minute-Remaining: 45
X-RateLimit-Hour-Limit: 1000
X-RateLimit-Hour-Remaining: 950

Error Responses

{
  "error": "Error type",
  "message": "Detailed error message"
}

Status Codes

  • 200: Success
  • 202: Accepted (async job queued)
  • 400: Bad request
  • 401: Unauthorized (missing API key)
  • 403: Forbidden (invalid API key)
  • 404: Not found
  • 413: Request too large
  • 429: Rate limit exceeded
  • 500: Internal server error
